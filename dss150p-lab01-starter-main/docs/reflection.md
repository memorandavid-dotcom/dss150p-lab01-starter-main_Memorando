# Laboratory 01 Reflection

I honestly took a bit of time to reflect on everything in this lab and had to solve things pretty slowly. At times, I felt a lot of doubt about how all these different tools and scripts connect, but I just pushed through and continued with the process. 

When looking at the different data sources, the Parquet file (`products.parquet`) seems like it would be the easiest to integrate into a future pipeline. Since it’s a binary format with its own schema already built-in, I wouldn't have to worry about the annoying type-mismatch errors that usually happen when importing basic CSVs. On the flip side, the REST API definitely presents the highest schema and data-quality risk. It was actually really hard obtaining and getting the API to work; I spent a lot of time trying to figure out how to make the API function dynamically without just hardcoding or pasting the exact API URL everywhere. Because external web services can change their JSON structure or data types without any warning, it could easily break the pipeline if strict rules aren't enforced.

There were quite a few files that I needed to take time to code and really understand based on extra research. Doing that made me realize what could go wrong if a pipeline is built before the source schema and data contracts are actually understood. If we skip making explicit data contracts upfront, unexpected schema changes will cause silent data corruption and break SQL joins down the line, ruining analytical dashboards. 

Finally, putting everything together was a steep learning curve. I found it really hard to commit to Git properly while I was constantly changing bits and pieces of everything to fix errors. Still, I can see how Git, virtual environments, Docker, and documentation improve a team's reproducibility. Docker makes sure the database runs the exact same way anywhere, `.venv` stops package versions from clashing, and despite my struggles with Git, having an auditable history means anyone can run the pipeline without guessing what I did.
